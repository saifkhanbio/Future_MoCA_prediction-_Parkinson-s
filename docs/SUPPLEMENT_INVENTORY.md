# Authorized supplementary files

These files are copied byte-for-byte from the manuscript's designated `Final_Manuscript/supplement` directory. The README uses the current manuscript title; the preserved appendix may retain an earlier working title. This release makes no editorial changes to its results or wording. Checksums are in `CODE_MANIFEST.json`.

| File | Content |
| --- | --- |
| `Supplementary_Appendix.docx` | Editable supplementary methods and aggregate tables |
| `Supplementary_Appendix.pdf` | PDF version of that appendix |
| `Supplementary_Appendix.txt` | Text version of that appendix |
| `Table_S3_All_54_Internal_Metrics.csv` | Aggregate metrics for 18 model recipes at three horizons |
| `Table_S4_All_459_Paired_Contrasts.csv` | Aggregate paired exploratory contrasts with conditional uncertainty intervals |
| `Table_S5_Feature_Selection_Frequencies.csv` | Feature selection frequency by model/horizon |
| `Table_S5b_All_270_Feature_Sets.csv` | Fold-level selected feature names, burden and applicable penalties; no participant assignments |
| `Table_S6_Temporal_Metrics_All_Sensitivities.csv` | Aggregate temporal clinical metrics and sensitivity views |
| `Table_S7_Original_RNA_Contrasts.csv` | Aggregate original RNA-extension contrasts |
| `Table_S8_Analysis_Lineage.csv` | Historical analysis questions and interpretation status |
| `Table_S9_Descriptive_Calibration.csv` | Aggregate descriptive calibration summaries |
| `Table_S10_Tuning_Comparison.csv` | Aggregate MAE-versus-MSE tuning comparison |

The CSVs contain no participant-level records or identifiers. Fold numbers describe model evaluations, not the assignment of individuals. The DOCX contains no embedded datasets or comments; its custom XML is an empty bibliography container. The PDF has no file attachments. Participant-level clinical/RNA data and predictions are not supplied.
