# Supplementary material

The current appendix integrates PPMI benchmarking, temporal evaluation and the independent LCC clinical-model experiment. Its journal name has been removed; numerical tables and embedded figures are preserved from the verified manuscript supplement. CSVs are copied without numerical edits. Source and released hashes are recorded in `CODE_MANIFEST.json`; source labels identify logical artifacts without journal-specific directory names.

The three frozen LCC implementation scripts are in `analysis/lcc_nominal_validation_2026-11-05/src/`, with [execution guidance](LCC_VALIDATION.md).

These are designated aggregate supplementary results. They contain no participant records, identity mappings, individual predictions or fold-membership assignments. Fold numbers describe model evaluations. Approved source access is required separately.
